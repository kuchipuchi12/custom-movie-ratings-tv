# What's good tonight

A personal page that lists what is streaming on your services in Bulgaria, with IMDb and Rotten Tomatoes scores, and filters for service, type, genre, year and minimum scores.

Open the page, press Settings, paste your own TMDB API Key and OMDb key, and tick your services. Keys are saved only in that browser. No keys are stored in this repository.

Streaming data and posters from TMDB. This product uses the TMDB API but is not endorsed or certified by TMDB. Ratings from OMDb.
